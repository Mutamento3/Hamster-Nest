# 普通私聊安排下一次接力

沿用 `cli_set_self_alarm`，参数不变。Claude relay 模式接受当前正在运行的接力任务，或当前 Claude singleton 普通私聊任务；旧任务、群聊、固定任务、其他角色和其他账号不获得新权限。

- 接力轮次仍先保存本轮决定，由结束后的 tick 续链。
- 私聊直接修改尚未执行的下一轮预约；已经排队的旧预约与命令一起退役，换新 wake_id，避免复用旧命令的幂等键。不存在预约时创建一个；始终只有一个 active relay。
- 私聊也可当天收工，撤销未执行预约。当天不能重新打开，次日自然恢复；正在运行的活动不由私聊改写。
- 当天 09:00–21:00、至少十分钟后、固定任务与 Codex 避让、30轮上限及到点聊天避让保留。成功仅表示预约写入，不能保证到点一定执行。

仅改数据库函数实现、MCP 描述与两份云端说明；无新表、无新 RPC 参数，不需要 Mini 重启或 App OTA。指南/菜单发布候选 v16，运行规则 v6 不变。以 `publication-baseline.json` 校验当前 ID/version/md5，再在同一事务通过既有发布 RPC 更新两份文档。

本地 PGlite 执行真实 migration，覆盖私聊改期/重试、队列撤销与新命令身份、收工与次日、角色/账号/任务/会话限制、时间/固定任务/Codex避让/每日上限；原接力回归保留。发布前后分别记录 schema、Edge、云端规则与自然调用证据。
